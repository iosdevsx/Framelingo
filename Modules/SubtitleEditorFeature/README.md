# SubtitleEditorFeature

Это UI редактирования субтитров. Модуль показывает список реплик, подробный редактор выбранного сегмента и окно предварительного просмотра перед импортом файла субтитров.

## Что внутри

Пакет разделён на два таргета:

- `SubtitleEditorFeature` — публичное состояние редактора, actions, модели фокуса, контракт document picker и фабрика компонентов.
- `SubtitleEditorFeatureImpl` — SwiftUI-экраны и их сборка.

Основные компоненты:

- `CueListView` показывает фильтруемый список cue с in/out, текстом, спикером, текущим и множественным выбором. Здесь есть add, split, merge, delete и создание шортса из выбранных строк.
- `EditorPaneView` редактирует спикера, тайминги, оригинал и перевод выбранного сегмента. Он показывает duration, CPS, длину строк и предупреждения; изменения текста отправляются с коротким debounce.
- `SubtitleImportPreviewSheet` показывает формат, кодировку, предупреждения и первые десять сегментов импортируемого файла. Пользователь выбирает destination и режим replace/append.
- `SubtitleEditorView` и `SubtitleTableRow` — старый табличный вариант редактора, который всё ещё доступен через публичную фабрику.
- `SubtitleEditorFocus` связывает фокус полей времени, оригинала и перевода с id сегмента.

## Откуда берутся данные

В `SubtitleEditorState` снаружи приходят субтитры, спикеры, labels, выбранные cue, активный по времени сегмент и ошибка autosave. UI не создаёт второй массив субтитров: выбор и любые изменения отправляются через `SubtitleEditorActions` владельцу проекта. Seek и показ ошибки тоже передаются callback-ами в request.

Системный выбор файла описан как `SubtitleDocumentPicker`. Реализацию для конкретной платформы подставляет composition layer; модуль различает выбранный URL, отмену и ошибку. Окно preview получает уже разобранный `SubtitleImportPreview` и лишь возвращает выбранный способ импорта.

## Что сюда не входит

Модуль не парсит файл субтитров, не применяет импорт, не сохраняет проект и не управляет воспроизведением. Он также не владеет каноническим выбором или undo/autosave: локальные draft-строки нужны только на время ввода, а итоговое изменение уходит наружу.

## Тесты

`SubtitleEditorFeatureImplTests` проверяет сохранение семантики document picker для success/cancel/failure и вычисляемые id в `SubtitleEditorFocus`. Поведение списка, валидация таймингов, debounce и import preview отдельными UI-тестами пока не покрыты.

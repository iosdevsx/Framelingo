# HomeFeature

Это стартовый экран Framelingo. Здесь пользователь выбирает или перетаскивает видео, открывает сохранённый файл проекта и возвращается к одному из недавних проектов.

## Что внутри

Пакет состоит из двух таргетов:

- `HomeFeature` — маленький публичный API. `HomeProjectOpening` передаёт загруженный `Project` оболочке приложения, которая уже решает, какой экран открыть.
- `HomeFeatureImpl` — `HomeView`, `HomeViewModel` и `HomeFeatureAssembly`.

`HomeView` показывает drop zone, системные панели выбора видео и файла проекта, ошибки и список Recent Projects. Поддерживаемые видеоформаты сейчас перечислены прямо в модуле: MP4, MOV, M4V, WEBM и MKV. Для проекта принимаются `.subtitleedit` и JSON.

`HomeViewModel` загружает каталог недавних проектов, проверяет формат видео, собирает `MediaFile`, пытается прочитать длительность и создаёт проект через репозиторий. Новый или импортированный проект попадает в каталог только после успешного сохранения. Для текущего MVP в новый проект добавляются переданные при сборке тестовые субтитры и статус `ready`.

## Откуда берутся данные

Модуль работает с несколькими внешними интерфейсами:

- `ProjectCatalogManaging` даёт снимок недавних проектов, публикует изменения и открывает проект по id;
- `ProjectRepository` создаёт и сохраняет проект;
- `ProjectFileServicing` читает импортируемый файл проекта;
- `MediaMetadataProviding` возвращает длительность видео;
- `HomeProjectOpening` отдаёт готовый проект оболочке приложения.

Доступ к файлам с security-scoped URL открывается только на время чтения или создания проекта. Если метаданные длительности недоступны, проект всё равно создаётся с `durationMs == nil`.

## Что сюда не входит

Home не редактирует проект, не запускает транскрипцию или перевод и не управляет навигационным состоянием приложения. Он также не реализует хранение каталога, JSON-формат проекта и извлечение медиаметаданных — только вызывает переданные сервисы.

## Тесты

`HomeFeatureImplTests` проверяет передачу открытого проекта наружу, порядок «сначала сохранить — потом добавить в каталог», поведение при ошибке сохранения, импорт файла проекта и понятную ошибку при несуществующем исходном видео.

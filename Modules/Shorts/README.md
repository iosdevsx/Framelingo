# Shorts

Модуль содержит доменную логику коротких вертикальных роликов: их диапазоны, настройки, подсказки по нарезке, ручное редактирование и подготовку данных для экспорта. Экран Shorts и сам запуск рендера находятся в других модулях.

## Как устроен пакет

- `Shorts` (`Sources/Api`) — модели и чистые правила работы с shorts.
- `ShortsImpl` (`Sources/Impl`) — сейчас в основном assembly, который отдаёт сервис подсказок и сервис пересчёта таймлинии.

Главная модель `ShortDefinition` хранит название, начало и конец на монтажной таймлинии, hook-текст, переопределение платформы и способ вертикального кадрирования. Для режима crop есть базовый `cropOffsetX` и дискретные `ShortCropKeyframe`: смещение переключается в заданный момент без интерполяции.

`ShortsExportSettings` задаёт общие настройки проекта: YouTube Shorts, Instagram Reels или TikTok, blur-pad/crop, отдельный стиль субтитров, hook, sidecar SRT и шаблон имени файла. Текст и тайминги субтитров при этом продолжают браться из общей коллекции проекта.

## Основные правила

- `ShortsSuggestionService` предлагает целые группы реплик, ориентируясь на длинные паузы, смену спикера и лимит выбранной платформы. Уже занятые диапазоны отфильтровываются.
- `ShortsEditingPolicy` добавляет, меняет и удаляет shorts, проверяет границы и поддерживает crop keyframes в допустимом диапазоне.
- `ShortsClipPlanner` переводит диапазон short из времени монтажной таймлинии в source-диапазоны для FFmpeg. Он же обрезает пересекающиеся субтитры и сдвигает их так, чтобы локальная шкала short начиналась с нуля.
- `SubtitleTimelineMappingService` пересчитывает субтитры, shorts и crop keyframes после ripple delete.
- `ShortsFilenameTemplate` раскрывает `{project}`, `{index}` и `{title}`, чистит имя для файловой системы и подбирает свободный URL без коллизий.

`ShortsPlatform` хранит реальные ограничения длительности и safe area для каждой площадки. Само построение вертикального видео по этим данным выполняет `VideoRendering`.

## Обычный сценарий

1. Сервис анализирует уже готовые субтитры и предлагает диапазоны.
2. Пользователь принимает подсказку или создаёт short вручную.
3. Editing policy сохраняет корректный диапазон, platform override и точки crop.
4. Перед экспортом planner получает source-клипы и локальные субтитры.
5. Фича передаёт их в `VideoRendering` и создаёт имя через filename template.

Модуль не хранит проект, не показывает UI и не запускает FFmpeg. Все его операции работают над переданными значениями и возвращают новые.

## Тесты

Проверяются предложения по паузам и спикерам, лимиты платформ, ручное редактирование, keyframes, JSON-совместимость моделей, mapping после удаления диапазона, подготовка клипов и субтитров, кириллица и коллизии в именах файлов.

```sh
swift test --package-path Modules/Shorts
```

# FFmpeg

Этот пакет подключает встроенные бинарники FFmpeg к приложению. В нём нет логики запуска команд, извлечения аудио или экспорта видео — он только делает собранный backend доступным другим модулям.

## Что внутри

В `Binaries` лежат локальные `xcframework` для `ffmpegkit` и библиотек FFmpeg: `libavcodec`, `libavdevice`, `libavfilter`, `libavformat`, `libavutil`, `libswresample` и `libswscale`.

Таргет `FFmpeg` подключает эти бинарники только на macOS. На этой платформе модуль реэкспортирует `ffmpegkit`, чтобы потребители могли работать с его API после импорта `FFmpeg`.

`FFmpegModule.isEmbeddedBackendAvailable` сообщает, включён ли встроенный backend в текущую сборку: для macOS это `true`, для остальных платформ — `false`. Пакет заявляет поддержку iOS 18, но бинарный backend там сейчас не подключается.

## Как используется

Модуль служит нижним слоем для кода, которому нужен встроенный FFmpeg. Выбор операций, аргументов, обработка прогресса и ошибок должны оставаться в сервисах более высокого уровня. Сам пакет не зависит от остальных модулей Framelingo.

## Тесты

Тест находится в `Tests/FFmpegTests` и проверяет, что значение `isEmbeddedBackendAvailable` соответствует платформе сборки. Работу отдельных кодеков и реальные медиаконвертации этот тест не запускает.

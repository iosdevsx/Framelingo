# ShortsFeature

Модуль содержит рабочую область для подготовки вертикальных коротких роликов. Здесь можно выбрать фрагменты исходного видео, посмотреть их в формате 9:16, настроить framing и оформление субтитров, а затем отправить выбранные шортсы на экспорт.

## Что внутри

В пакете два библиотечных таргета:

- `ShortsFeature` — состояние рабочей области, набор действий, request и фабрика SwiftUI-компонента.
- `ShortsFeatureImpl` — вертикальный preview, правая панель шортсов, popover-настройки и адаптеры расчёта caption layout.

`ShortsWorkspaceView` строится вокруг preview и одной контекстной панели:

- `ShortsVerticalPreview` показывает видео на вертикальном холсте. Доступны blurred background и crop, safe area выбранной платформы, текущий субтитр и hook title. В crop-режиме кадр можно двигать по горизонтали; позиция сохраняется для текущего времени. Сам caption тоже можно перетащить.
- Контекстная панель переключается между `Clips` и `Edit`. В `Clips` находятся фрагменты и предложения; выбор фрагмента сразу открывает `Edit` с title, hook, платформой, framing и caption-настройками. Crop-фокус и crop points показываются только для режима Crop.
- Создание, предложения, defaults и экспорт находятся в header/footer этой панели. Отдельной верхней панели действий и нижнего инспектора у фичи больше нет.

Отдельные popover-компоненты меняют общие настройки шортсов, стиль burned-in субтитров и параметры экспорта, включая создание соседнего `.srt`.

## Откуда берутся данные

Рабочая область получает единый `ShortsWorkspaceState`: субтитры, массив `ShortDefinition`, настройки экспорта, текущее время, выбор, предложения и размеры исходного видео. `AVPlayer` также приходит снаружи.

Все изменения уходят владельцу состояния через `ShortsWorkspaceActions`: выбор и редактирование фрагмента, crop keyframes, subtitle style, принятие предложений и запуск экспорта. Для seek используется отдельный callback. Интерактивные drag/slider-сессии имеют begin/end actions, чтобы внешний слой мог собрать изменение в одну undo-операцию.

## Что сюда не входит

Модуль не хранит проект и не выполняет экспорт видео сам. Он не генерирует предложения и не владеет undo-стеком — только вызывает переданные действия. Нижний общий таймлайн также находится не здесь: его рисует `TimelineFeature`, а рабочий экран проекта соединяет оба модуля.

## Тесты

`ShortsFeatureTests` проверяет вычисление выбранного шорта без второго массива-состояния и явные взаимно исключающие режимы `Clips`/`Edit`. Crop, preview, popover-компоненты и экспортный сценарий автоматическими тестами этого пакета пока не покрыты.

```sh
swift test --package-path AppTarget/Modules/Features/ShortsFeature
```

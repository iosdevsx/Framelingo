# PlayerFeature

Модуль показывает видео проекта вместе с текущими субтитрами. Это именно preview для рабочего экрана: он использует уже созданный `AVPlayer`, рисует поверх него оформление субтитров и при необходимости показывает простые кнопки воспроизведения.

## Что внутри

В пакете два таргета:

- `PlayerFeature` — публичные state/actions/request, фабрика preview и чистая утилита `TimelineFrameStepper`.
- `PlayerFeatureImpl` — SwiftUI-предпросмотр, macOS-обёртка над `AVPlayerView` и сборка фабрики.

`ProjectVideoPreview` находит активный `SubtitleSegment` по `currentTimeMs`, предпочитает переведённый текст и берёт оригинал, если перевод пуст. Шрифт, цвет, фон, рамка, число строк и позиция читаются из `project.videoExportSettings`. Субтитр можно перетащить внутри реальной области видео; новая нормализованная позиция уходит наружу через action.

`MacVideoPlayerView` отключает стандартные контролы `AVPlayerView`, потому что play/pause и время рисует SwiftUI-слой. `TimelineFrameStepper` вычисляет соседнюю границу кадра для заданного frame rate и ограничивает результат длительностью ролика.

## Откуда берутся данные

Оболочка передаёт `ProjectVideoPreviewRequest`: проект, `AVPlayer`, текущее время, состояние воспроизведения, флаг показа контролов и `VideoSourceInfo`. В ответ модуль вызывает только два действия — переключение play/pause и обновление `VideoExportSettings` с флагом регистрации undo.

Сам `AVPlayer` и его время остаются внешними. Модуль не добавляет time observer и не создаёт player item.

## Что сюда не входит

Здесь нет загрузки видео, управления жизненным циклом плеера, seek, таймлайна, редактирования текста субтитров и экспорта. Preview лишь отображает полученное состояние и сообщает о пользовательских действиях владельцу проекта.

## Тесты

`PlayerFeatureImplTests` проверяет `TimelineFrameStepper`: шаг по NTSC 29.97 fps, переход к соседней границе из произвольной позиции и ограничение временем начала/конца. Визуальный preview тестами не покрыт.

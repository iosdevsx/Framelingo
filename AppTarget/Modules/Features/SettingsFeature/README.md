# SettingsFeature

Это экран настроек приложения. В нём собраны выбор локального движка распознавания, установка моделей, проверка FFmpeg, внешний вид редактора и стиль субтитров активного проекта.

## Что внутри

Пакет публикует два таргета:

- `SettingsFeature` — пока только пустая публичная точка входа без собственных моделей.
- `SettingsFeatureImpl` — `SettingsView`, `SettingsViewModel`, список разделов и `SettingsFeatureAssembly`.

В боковой панели есть четыре раздела:

- **Tools** — выбор Speech-to-Text и Translation provider, установка Whisper и VAD, загрузка моделей Parakeet, путь и проверка FFmpeg;
- **Appearance** — accent color приложения и редактор стиля burned-in субтитров активного проекта с preview;
- **Shortcuts** — справочный список горячих клавиш;
- **About** — название и текущая alpha-версия приложения.

`SettingsViewModel` показывает прогресс установки моделей, статус FFmpeg и ошибки сохранения. Глобальные `AppSettings` и настройки экспорта активного проекта разведены намеренно: изменение оформления субтитров не записывается как глобальная настройка.

## Откуда берутся данные

`SettingsFeatureAssembly.makeView` получает готовые зависимости от слоя приложения:

- `SettingsAccess` даёт текущий снимок настроек, поток обновлений и принимает изменения;
- `ActiveProjectExportSettingsManaging` читает и меняет `VideoExportSettings` выбранного проекта;
- `WhisperModelManaging` и `ParakeetModelManaging` устанавливают локальные модели;
- фабрика `FFmpegService` проверяет доступность выбранного video backend;
- флаг `usesEmbeddedVideoRenderingBackend` определяет, показывать встроенный FFmpegKit или редактируемый путь к бинарнику.

## Что сюда не входит

Модуль не хранит настройки на диске, не скачивает модели самостоятельно, не реализует FFmpeg и не выбирает активный проект. Он показывает состояние внешних сервисов и отправляет им изменения. Раздел Shortcuts сейчас только справочный — переназначения клавиш здесь нет.

## Тесты

`SettingsFeatureImplTests` проверяет два важных разделения ответственности: глобальные настройки сохраняются через `SettingsAccess` и показывают ошибку persistence, а стиль экспорта проекта обновляется через отдельный адаптер и не меняет глобальные настройки. Установка моделей, проверка FFmpeg и SwiftUI-экран отдельно не тестируются.

```sh
swift test --package-path AppTarget/Modules/Features/SettingsFeature
```

# ExportFeature

Этот модуль содержит интерфейс экспорта видео и субтитров, а также небольшие уведомления о долгих экспортных задачах. Он отвечает за то, что пользователь видит перед запуском экспорта и после него: выбор файла, параметры кодирования, сообщения об ошибках, ссылку на готовый результат.

## Что внутри

Пакет собирает два библиотечных таргета:

- `ExportFeature` — публичные состояния, действия и фабрика экранов. Здесь же описаны адаптеры для показа файла в Finder, копирования диагностики и чтения общей ленты фоновых задач.
- `ExportFeatureImpl` — SwiftUI-экраны и их сборка.

Основные компоненты реализации:

- `ExportVideoSheet` показывает выбор выходного MP4, режим текста субтитров, разрешение, частоту кадров, кодек, качество, preset и простой предпросмотр оформления.
- `ExportVideoViewModel` читает метаданные исходного видео и подбирает доступные разрешения и frame rate. Сам рендер выполняет `VideoExport` после отправки формы.
- `SubtitleExportOptionsSheet` настраивает подписи спикеров для SRT/VTT. Для WebVTT он использует voice tags, для остальных вариантов — квадратные скобки либо отключает подписи.
- `ActivityToastOverlay` показывает до четырёх текущих задач, прогресс, ошибку и действия вроде Reveal in Finder или Copy Debug.
- `ExportFeatureAssembly` связывает публичную фабрику с реализацией и получает все внешние сервисы через параметры.

## Откуда берутся данные

Видеоэкспорт открывается через `VideoExportPresentationRequest`: снаружи приходят `Project` и callback, которому экран передаёт `VideoExportSubmission` с настройками, метаданными и выбранным URL. Submission превращается в неизменяемый запрос `VideoExport`, а слой сборки подставляет сервис чтения метаданных.

Настройки текстового экспорта приходят в `SubtitleExportOptionsRequest`; модуль меняет их через `SubtitleExportOptionsActions`, но сам не хранит настройки проекта. Уведомления читаются из `ProductActivitySource`, а закрытие уведомления отправляется его настоящему владельцу.

## Что сюда не входит

Модуль не владеет проектом, очередью фонового экспорта и общей историей задач. Он не решает, когда сохранять обновлённые настройки проекта, и не реализует FFmpeg, генератор ASS, экспорт SRT/VTT или системные операции Finder/clipboard. Здесь находятся UI и координация этих зависимостей, а не их низкоуровневая реализация.

## Тесты

`ExportFeatureTests` проверяет публичные контракты: передачу настроек текстового экспорта, результаты Reveal/Copy и публикацию прогресса с маршрутизацией dismiss к владельцу. UI и полный прогон FFmpeg этими тестами не покрыты.

```sh
swift test --package-path AppTarget/Modules/Features/ExportFeature
```

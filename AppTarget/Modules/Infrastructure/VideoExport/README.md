# VideoExport

Этот модуль принимает уже подготовленное задание на экспорт видео и доводит его до готового файла. Здесь живут очередь заданий, прогресс, понятные ошибки и запуск рендера через FFmpeg.

`VideoExport` содержит только публичные модели и контракт очереди. Его можно подключить к интерфейсу или другому продукту, не зная, как именно устроен рендер. `VideoExportImpl` последовательно выполняет задания, создаёт временные ASS-файлы, вызывает сервисы из `VideoRendering`, пишет SRT рядом с шортсом и убирает временные файлы после работы.

Планирование шортсов сюда не входит: модуль получает уже нормализованный `ShortExportPlan` из `Shorts`. Низкоуровневые настройки кодека, геометрия и сборка FFmpeg-команд остаются в `VideoRendering`.

## Тесты

Тесты проверяют последовательную очередь, прогресс, отмену, cleanup временных
файлов и передачу нормализованного задания в рендерер.

```sh
swift test --package-path AppTarget/Modules/Infrastructure/VideoExport
```

# Project

`Project` описывает сохранённый проект Framelingo и отвечает за его хранение на диске. Это место, где сходятся ссылки на исходное видео, субтитры, спикеры, монтажный таймлайн, шорты и настройки экспорта.

Модуль не показывает интерфейс и не запускает расшифровку или рендеринг. Он даёт остальному приложению общую модель проекта и понятные операции сохранения, загрузки и удаления.

## Что внутри

Пакет разделён на два таргета:

- `Project` — публичные модели, протоколы и небольшие правила вокруг проекта;
- `ProjectImpl` — файловая реализация хранилища, каталог недавних проектов и импорт/экспорт project-файлов.

Основные типы:

- `Project` — корневая `Codable`-модель. Массив `subtitles` здесь является единственным источником истины для редактора и таймлайна;
- `MediaFile` и `ProcessingStatus` — сведения об исходном файле и текущем состоянии обработки;
- `ProjectRepository` — контракт создания, сохранения, загрузки, списка и удаления проектов;
- `FileProjectRepository` — хранит `project.json` в `Application Support/Framelingo/Projects/<UUID>` и проверяет, что исходное видео всё ещё доступно;
- `ProjectCatalogManaging` и `DefaultProjectCatalog` — поддерживают отсортированный список недавних проектов и публикуют ошибки открытия, очистки и удаления;
- `ProjectFileServicing` — экспортирует проект в отдельный JSON-файл и импортирует его обратно;
- `ExportClipPlanResolver` — решает, экспортировать всё видео или передать рендереру сохранённые диапазоны монтажного таймлайна.

## Формат и совместимость

`Project` сохраняется обычным JSON с ISO 8601 для дат. Новые поля декодируются с разумными значениями по умолчанию, поэтому старые project-файлы продолжают открываться после добавления word timings, спикеров, таймлайна, шортов и настроек экспорта.

Репозиторий хранит ссылку на исходное видео, а не копию самого файла. Если файл перемещён или удалён, загрузка возвращает понятную ошибку `videoFileMissing`.

## Как используется

Экранные модули меняют копию `Project` через свои модели состояния и сохраняют её посредством `ProjectRepository`. Каталог держит только короткие `ProjectSummary`, чтобы домашнему экрану не приходилось загружать все данные каждого проекта.

Перед удалением каталог вызывает `PreparedMediaCleanup`. Это позволяет убрать подготовленное аудио и другие временные файлы до удаления JSON проекта, не связывая `ProjectImpl` с конкретной реализацией подготовки медиа.

## Тесты

Тесты в `Tests/ProjectImplTests` проверяют полный цикл файлового репозитория, сортировку и ошибки каталога, порядок очистки при удалении, построение плана клипов и повторное чтение старого примера JSON после сохранения.

Запуск:

```sh
swift test --package-path AppTarget/Modules/Core/Project
```

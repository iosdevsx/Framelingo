# Subtitles

Это основной модуль для текстовых субтитров. Здесь находится модель строки, правила редактирования таймингов, импорт файлов и экспорт SRT, VTT и TXT. UI остаётся снаружи: модуль принимает обычные значения и возвращает обновлённые массивы или пишет готовый файл.

## Публичный API

Таргет `Subtitles` содержит `SubtitleSegment` — строку с индексом, началом и концом в миллисекундах, оригинальным и переведённым текстом, данными спикера, уверенностью и предупреждениями.

Рядом находятся:

- модели выбора формата, режима импорта и варианта экспортируемого текста;
- `SubtitleTimingValidator`, который двигает и растягивает строки с минимальной длительностью 500 мс, зазором 50 мс и ограничением по длине видео;
- `SubtitleStructuralEditingPolicy` для split, merge, add и delete без переноса этой логики в SwiftUI;
- `SubtitleImportMergePolicy` для замены или добавления импортированных строк в оригинальный либо переведённый текст;
- `SubtitleWarningService`, который считает скорость чтения и предупреждает о слишком коротких, длинных или широких строках;
- протоколы импорта, экспорта, SRT-парсинга и работы с таймкодами.

API зависит от `SpeakerAnalysis`: оттуда приходят speaker labels и предупреждения диаризации.

## Импорт и экспорт

`SubtitlesImpl` собирается через `SubtitlesAssembly` и содержит файловые сервисы.

Импорт распознаёт SRT, WebVTT, ASS/SSA, SBV и обычный TXT. Чтение поддерживает UTF-8, варианты UTF-16 и Windows-1251. Парсеры убирают служебную разметку, нормализуют переносы строк, сортируют строки и пересчитывают индексы. Поскольку TXT не хранит время, для его блоков создаются примерные трёхсекундные интервалы и предупреждение для пользователя.

Экспорт пишет оригинальный или переведённый SRT/VTT, а также TXT. Для перевода можно включить fallback на оригинал. При наличии `SpeakerLabel` SRT умеет добавлять имя в квадратных скобках, а WebVTT — voice tags; по умолчанию подписи спикеров выключены.

Основной поток выглядит так: importer возвращает `SubtitleImportPreview`, вызывающая фича выбирает режим слияния через `SubtitleImportMergePolicy`, редактор меняет тот же массив `SubtitleSegment`, а exporter получает `SubtitleExportRequest` и записывает выбранный файл.

## Тесты

Тесты находятся в `Tests/SubtitlesImplTests`. Они покрывают:

- разбор SRT, VTT, ASS и TXT, очистку разметки и нормализацию порядка;
- форматирование и парсинг таймкодов, SRT export и round-trip parse/export;
- ограничения перемещения и изменения границ на таймлайне;
- split, merge, add, delete и правила слияния импорта;
- совместимость старого JSON `SubtitleSegment` с новыми speaker-полями;
- экспорт подписей спикеров и независимость текстового экспорта от оформления видео;
- предупреждение о слишком высокой скорости чтения.

```sh
swift test --package-path AppTarget/Modules/Core/Subtitles
```

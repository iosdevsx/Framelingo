# Media

Модуль собирает базовую работу с локальными медиафайлами: читает длительность и параметры видео, а также строит данные для отображения звуковой волны. Внешний код работает через протоколы и не зависит напрямую от AVFoundation или формата кеша.

## Таргеты и основные компоненты

`Media` содержит публичные контракты и модели:

- `MediaMetadataProviding` возвращает длительность, размеры кадра и номинальную частоту кадров;
- `WaveformLoading` строит массив нормализованных пиков, принимает `WaveformRequest` и сообщает прогресс через callback;
- `AudioPreparationService` описывает подготовку аудио и его последующую очистку;
- `WaveformCache`, `VideoMetadata` и ошибки фиксируют формат данных на границе модуля.

`MediaImpl` содержит рабочие реализации и `MediaAssembly`:

- `MediaMetadataService` читает метаданные через AVFoundation и учитывает поворот кадра из `preferredTransform`;
- `WaveformService` сначала ищет подходящий `waveform.json`, а при промахе просит вызывающий код предоставить WAV-файл, анализирует его и сохраняет результат;
- `WaveformPeakAnalyzer` поддерживает несжатый PCM WAV с 16-битными сэмплами и сводит звук к массиву значений от 0 до 1;
- `PassthroughAudioPreparationService` пока просто возвращает исходный URL и ничего не удаляет.

## Поток данных

Для волны вызывающий код передаёт сведения о проекте и медиафайле. Сервис сравнивает путь, размер, дату изменения, длительность и версию кеша. Если кеш актуален, извлечение аудио не запускается. Иначе callback `audioProvider` готовит WAV, анализатор вычисляет пики, а сервис пишет кеш в `Application Support/<appName>/Projects/<project-id>/waveform.json`.

Такой callback оставляет извлечение аудио за соседним FFmpeg-сервисом и не связывает `Media` с конкретной реализацией конвертации.

## Тесты

Тесты находятся в `Tests/MediaImplTests`. Они проверяют, что валидный кеш возвращается без вызова `audioProvider`, и что passthrough-подготовка сохраняет исходный URL, включая путь с пробелами и кириллицей. Чтение реального видео через AVFoundation и разбор WAV отдельными тестами пока не покрыты.

```sh
swift test --package-path AppTarget/Modules/Core/Media
```

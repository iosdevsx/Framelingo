# Timeline

Модуль хранит и редактирует виртуальный монтажный план. Он не режет исходный файл: вместо этого описывает, какие диапазоны исходного видео идут друг за другом на таймлинии после удалений и разрезов.

## Как устроен пакет

- `Timeline` (`Sources/Api`) — модели монтажной таймлинии, протокол редактирования и чистые функции для отображения больших данных.
- `TimelineImpl` (`Sources/Impl`) — реализация операций над клипами.

`EditTimeline` содержит упорядоченный массив `TimelineClip` и итоговую длительность. Каждый клип хранит две пары координат: диапазон в исходнике и соответствующий диапазон на смонтированной таймлинии. `VideoCutRange` описывает удаляемый интервал.

Протокол `EditTimelineEditing` поддерживает создание начального плана, ripple delete, split, удаление клипа, перевод времени таймлинии во время исходника и поиск текущего клипа. `playbackAdvance` подсказывает плееру, продолжать ли текущий клип, перейти к следующему, закончить воспроизведение или остаться на паузе.

`TimelinePerformance` содержит чистые расчёты для UI: видимый диапазон с буфером, выбор видимых и активных субтитров и уменьшение массива waveform peaks до бакетов подходящего размера.

## Реализация и границы

`EditTimelineService` делает все правки над значениями и после каждой операции пересчитывает непрерывные координаты таймлинии. Ошибки вроде пустой длительности, неверного диапазона, удаления всей таймлинии или разреза за её пределами описаны в `EditTimelineError`.

`TimelineAssembly.makeEditingService()` — точка сборки реализации.

Здесь нет SwiftUI, управления плеером, субтитрами проекта или запуска FFmpeg. Другие модули используют получившийся план: `VideoRendering` превращает клипы в фильтры FFmpeg, а `Shorts` пересчитывает по нему диапазоны коротких роликов.

## Обычный сценарий

1. Для исходной длительности создаётся один клип.
2. Пользователь удаляет диапазон или делит клип.
3. Сервис меняет source-диапазоны и заново укладывает клипы без разрывов во времени таймлинии.
4. Плеер использует mapping и `playbackAdvance`, а экспорт получает тот же порядок клипов.

## Тесты

Тесты покрывают удаления в начале, середине, конце и через несколько клипов, split, пересчёт координат, mapping времени и переходы плеера у границ. Отдельно проверяются выбор видимых субтитров и downsampling waveform.

```sh
swift test --package-path AppTarget/Modules/Core/Timeline
```

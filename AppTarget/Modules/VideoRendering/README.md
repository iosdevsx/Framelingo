# VideoRendering

Модуль отвечает за техническую подготовку и финальный рендер видео через FFmpeg. Он извлекает аудио, собирает команды экспорта, создаёт ASS-субтитры и умеет впечь их в обычное или вертикальное видео.

## Как устроен пакет

- `VideoRendering` (`Sources/Api`) — публичные настройки экспорта, модели геометрии и протоколы.
- `VideoRenderingImpl` (`Sources/Impl`) — запуск FFmpeg, генерация ASS и построение аргументов командной строки.

Центральный контракт `FFmpegService` умеет проверить доступность FFmpeg, извлечь аудио и выполнить экспорт с субтитрами. Операции принимают массив `ExportClipRange`, поэтому могут работать как с исходным видео целиком, так и с виртуально смонтированным таймлайном. Прогресс приходит как обработанное время в миллисекундах.

`SubtitleScriptGenerating` отделяет подготовку ASS-скрипта от самого рендера. Остальной публичный API описывает:

- внешний вид субтитров и параметры кодирования в `VideoExportSettings`;
- разрешение, частоту кадров, кодек, качество и preset;
- данные исходного видео и расчёт выходной геометрии;
- вертикальный режим `blurPad` или `crop`, горизонтальное смещение и crop keyframes;
- вертикальные safe area, hook-текст и раскладку подписей.

## Реализации

На macOS `VideoRenderingAssembly.makeDefaultService()` возвращает встроенный backend из модуля `FFmpeg`. Для сценариев с внешним бинарником есть `makeProcessService`, который запускает `Process` с массивом аргументов. На неподдерживаемой платформе используется явная реализация, возвращающая ошибку недоступности.

`FFmpegExportArgumentsBuilder` строит фильтры для монтажа клипов, масштабирования, FPS, субтитров и вертикального reframing. Он не собирает shell-строку для запуска процесса. `FFmpegProgressParser` читает машинный прогресс FFmpeg.

`ASSSubtitleExportService` генерирует обычные и вертикальные ASS-скрипты: переносит строки, рисует фон и рамку, выбирает переведённый текст с fallback на оригинал и удерживает подписи и hook внутри safe area. `BurnedSubtitleLayoutHelper` содержит общие расчёты раскладки, которые можно использовать и в превью.

`FFmpegAudioPreparationService` готовит WAV через `Media.AudioPreparationService`, кэширует его по URL исходника и умеет удалить кэш.

## Обычный поток данных

1. Вызывающий код определяет клипы, настройки и сведения об исходном видео.
2. Генератор создаёт ASS-файл из сегментов субтитров.
3. `VideoExportGeometry` выбирает допустимые размер и FPS без ненужного апскейла.
4. Builder формирует аргументы FFmpeg. Для вертикального видео добавляется blur-pad или crop с keyframes.
5. Сервис запускает рендер, сообщает прогресс и возвращает URL готового файла.

Модуль не хранит проекты, задания или очередь и не решает, какие именно shorts экспортировать. План готовит `Shorts`, а последовательное выполнение и состояние заданий принадлежат `VideoExport`.

## Тесты

Покрыты аргументы извлечения и рендера, монтаж нескольких клипов, вертикальные crop/blur-pad фильтры, геометрия и FPS, обратная совместимость настроек, ASS-разметка, safe area и совпадение раскладки с превью. Есть smoke-тесты встроенного FFmpeg для извлечения аудио и видео с впечёнными субтитрами.

```sh
swift test --package-path AppTarget/Modules/VideoRendering
```

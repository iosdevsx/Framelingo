# Application

`Application` хранит состояние и операции, которые относятся ко всему приложению, а не к одному экрану. Сейчас это прежде всего очередь экспорта видео и общий индикатор расшифровки.

Модуль не собирает интерфейс и не выбирает конкретные реализации сервисов. Он получает готовые зависимости извне и связывает их в прикладные сценарии.

## Что внутри

Пакет разделён на два таргета:

- `Application` — публичные типы, состояние приложения и логика экспорта;
- `ApplicationImpl` — небольшая точка сборки `ApplicationAssembly`, которая создаёт `AppState`.

Основные части:

- `AppState` — `@MainActor`-объект, за которым наблюдает интерфейс. Он хранит очередь `VideoExportJob`, запускает задания по одному и публикует состояние текущей расшифровки;
- `AppStateDependencies` — явный список сервисов, нужных `AppState`;
- `VideoExportWorker` — выполняет один экспорт: проверяет исходный файл, готовит ASS-субтитры, вызывает FFmpeg и при необходимости пишет SRT рядом с шортом;
- `ShortExportPlan` и `ShortsReframeMapper` — переводят настройки конкретного шорта в понятный рендереру план;
- `ApplicationExportError`, `VideoExportFailure` и типы задания — описывают ошибки и состояние очереди без привязки к SwiftUI.

## Как проходит экспорт

Экран передаёт в `AppState` снимок проекта и настройки. `AppState` добавляет задание в очередь и запускает следующий ожидающий экспорт. `VideoExportWorker` строит набор клипов, создаёт временный ASS-файл и передаёт работу сервису `FFmpegService`. Прогресс и понятное пользователю описание ошибки возвращаются в то же задание.

Обычный экспорт требует субтитры. Экспорт шорта может состоять только из видео и hook-текста; для него также поддерживаются вертикальное кадрирование и необязательный SRT-файл рядом с MP4.

## Связи с другими модулями

`Application` использует модели проекта, настройки, подготовку аудио, перевод, анализ спикеров, субтитры и видеорендеринг. Конкретные реализации этих сервисов выбирает `MacFeature`, поэтому здесь нет зависимости от AppKit, экранов или файловых панелей.

Логика самой расшифровки и перевода живёт в `TranscriptionPipeline` и `TranslationPipeline`. `Application` только предоставляет общие сервисы и состояние, которое должно быть видно в разных частях приложения.

## Тесты

Тесты находятся в `Tests/ApplicationImplTests`. Пока здесь закреплено пользовательское сообщение для ошибки пустого монтажного таймлайна. Основные сценарии экспорта дополнительно проверяются в модулях, которые владеют FFmpeg, рендерингом и экраном проекта.

Запуск тестов пакета:

```sh
swift test --package-path AppTarget/Modules/Application
```
